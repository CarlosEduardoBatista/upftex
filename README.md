# UPFTeX

Customizacao institucional do Overleaf Community Edition (v6.3.0) para a
Universidade de Passo Fundo, desenvolvida como Trabalho Final de Curso.

Abordagem: overlay sobre a imagem oficial sharelatex/sharelatex:6.3.0,
adicionando (1) branding institucional e (2) autenticacao via Google
Workspace (OAuth2/OIDC).
